# Morrow Dawn 官网

这是可直接放到 GitHub Pages 的纯静态网站，无需安装任何依赖。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库，把本文件夹中的全部文件上传到仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`，保存即可。

下载按钮已连接参考网站当前使用的公开下载地址。如需更换，在 `index.html` 中搜索 `files.zohopublic.com.cn` 并替换链接。
